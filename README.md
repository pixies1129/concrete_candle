# CANDLE STUDIO AI

캔들 제품 사진 한 장으로 스마트스토어·인스타그램용 마케팅 이미지를 만드는 AI 기반 PWA.

> "캔들 사진 한 장으로, 브랜드 화보를 만들어보세요."

## 핵심 원칙
AI는 제품(용기 형태·색상·라벨·질감)을 절대 새로 그리지 않는다. 배경·조명·분위기만 바꿔 "실제 판매 제품을 고급 스튜디오에서 촬영한 것처럼" 보이게 만드는 것이 목표다.

## 현재 상태 (STEP 1)
업로드 → 스타일 선택(출력 타깃/촬영 콘셉트/소품) → 생성 결과의 3단계 위저드 UI가 완성되어 있다. AI 이미지 생성은 아직 목업(`MockProvider`)이며, 실제 Gemini 연동은 다음 단계에서 진행한다.

## 개발

```bash
npm install
npm run dev
```

## 타입 체크 / 빌드

```bash
npm run typecheck
npm run build
```
